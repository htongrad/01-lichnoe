# Google Диск и Календарь · панель 01

1. Открой панель в привычном профиле Chrome. В «Обзоре» нажми кнопку синхронизации.
2. При первом подключении укажи Client ID, номер проекта Google Cloud и ключ Google Picker. Если Chrome сохранил настройки, достаточно войти в прежний аккаунт.
3. Разреши доступ и при запросе выбери папку «01 ЛИЧНОЕ». Для зеркала используется основной календарь.
4. После сохранения события или заметки открытая панель отправляет изменения автоматически при доступном интернете и действующем разрешении Google. На закрытом телефоне по расписанию отправка не выполняется. После повторного открытия нажми «Синхронизировать», если требуется доступ.
5. Для восстановления открой ⋯ → Синхронизация Google → Восстановить последнюю копию. Сверь количество событий и заметок и подтверди добавление. Если копия недоступна, панель ищет предыдущую исправную.

В Google Cloud для проекта включают Drive API, Calendar API и Google Picker API. В настройках OAuth для веб-приложения разрешённый JavaScript origin — `https://htongrad.github.io`. Для ключа Picker укажи разрешённый сайт `https://htongrad.github.io/*` и Google Picker API.
