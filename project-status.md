# Паспорт панели 01 «Личное»

Рабочий адрес — [Панель 01](https://htongrad.github.io/01-lichnoe/). Код публикуется из `main:/docs` через GitHub Pages. Номер версии виден в меню **⋯**.

Версия 1.2.0 добавляет кнопку **«Синхронизировать»** в Обзор. Она запускает сохранение копии и отправку событий. Копии с изменениями сохраняются отдельными файлами с датой. Восстановление последней копии доступно в меню Google.

Записи хранятся в браузере. Google Диск хранит копии в папке **«01 ЛИЧНОЕ»**, а основной Google Календарь получает зеркало событий с сохранённым часовым поясом. [Настройка Google и восстановление](google-sync-setup.md).

Разделы панели — **Обзор**, **Календарь** и **Заметки**. Календарь показывает события дня, недели и месяца. Повторяющиеся события можно изменить по одному, начиная с выбранного события или для всей серии.
