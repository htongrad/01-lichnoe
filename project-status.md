# Паспорт панели 01 «Личное»

Рабочий адрес — [Панель 01](https://htongrad.github.io/01-lichnoe/). Код публикуется из `main:/docs` через GitHub Pages. Номер версии виден в меню **⋯**.

Версия 1.1.0 включает восстановление копии в пустой рабочей папке, импорт собственной JSON-копии с учётом места в браузере, обновление даты «Сегодня» без перезагрузки и сохранение часового пояса событий для Google Календаря.

Записи хранятся в браузере. Google Диск хранит копию в папке **«01 ЛИЧНОЕ»**, а основной Google Календарь получает зеркало событий. [Настройка Google и восстановление](google-sync-setup.md).

Разделы панели — **Обзор**, **Календарь** и **Заметки**. Календарь показывает события дня, недели и месяца. Повторяющиеся события можно изменить по одному, начиная с выбранного события или для всей серии.
