# Паспорт панели 01 «Личное»

Рабочий адрес — [Панель 01](https://htongrad.github.io/01-lichnoe/). Код публикуется из `main:/docs` через GitHub Pages. Номер версии виден в меню **⋯**.

Версия 1.3.0 использует согласованный дизайн «Модули». В **Обзоре** показаны события на сегодня, следующие семь дней и три последние заметки. Кнопка **«Синхронизировать»** расположена после этих карточек. Она запускает сохранение копии и отправку событий. Копии с изменениями сохраняются отдельными файлами с датой. Восстановление последней копии доступно в меню Google.

Записи хранятся в браузере. Google Диск хранит копии в папке **«01 ЛИЧНОЕ»**, а основной Google Календарь получает зеркало событий с сохранённым часовым поясом. [Настройка Google и восстановление](google-sync-setup.md).

Разделы панели — **Обзор**, **Календарь** и **Заметки**. Календарь показывает один выбранный период — день, неделю или месяц. В сетке отмечены даты с событиями, а кнопка **«Сегодня»** возвращает к текущему дню. Повторяющиеся события можно изменить по одному, начиная с выбранного события или для всей серии. Нажатие на название или значок в шапке открывает Обзор.
